      模型与 API 配置

      写入执行器 · 改后自动重启

      按阶段指定模型

      文本阶段用快模型 · 开发阶段用强模型

      可以给单个阶段指定模型，未指定的阶段继续用默认模型。此项会重启执行器并中断正在运行的任务，因此改动需点击「应用更改」并二次确认，单纯切换下拉不会写入。

      配音音色

      下一次出片生效 · 不重启执行器

      选择下一次视频合成使用的中文配音。切换不会中断正在运行的任务。在线音色由微软 Edge 神经语音实时合成，出片时需要联网；所有音色当前均为测试用途，对外发布前需自行确认授权。
